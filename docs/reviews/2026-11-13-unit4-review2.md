**1. Ranked findings**

1. **U4-R2-01 — P2 — A partial-clone scan changes the source repository and can start a remote helper.**
   `tools/git_child.py:39`, `tools/make_public_snapshot.py:165`. **Reproduced.** With no inherited `GIT_*` variables, scanning a fake partial clone fetched its missing blob from a local fake remote, added four pack-related files inside the source `.git`, and reported `CLEAN`. A second fixture's configured remote helper executed and wrote a sentinel before the tool reported refusal and "Nothing was written." Disabling optional locks does not disable lazy fetching.
   **Closing test:** Scan a partial clone with missing objects. Require refusal without fetching, starting a helper, or changing any source-repository bytes.

2. **U4-R2-02 — P2 — A line allow marker extends across carriage-return boundaries.**
   `tools/make_public_snapshot.py:368`. **Reproduced.** A file containing `synthetic@example.test # public-snapshot: allow email<CR>private.review@private.invalid` was published. Changing that carriage return to LF correctly refused the private address. U+2028 produced the same bypass. Splitting only on LF lets a marker silence subsequent visible lines.
   **Closing test:** Exercise mixed LF, CRLF, lone CR and Unicode line separators. An allow marker must not exempt an address on a subsequent line.

3. **U4-R2-03 — P2 — Internationalized domains containing combining marks escape the e-mail rule.**
   `tools/make_public_snapshot.py:119`. **Reproduced.** Both `owner@उदाहरण.भारत` and `owner@q̇a.de` were published unchanged. Both domains are NFC; Python's IDNA codec converts them to ASCII. The domain's `\w` character class excludes their combining marks, so the regex finds no address. Neither address was listed or marked.
   **Closing test:** Add canonical IDN fixtures containing combining marks, including these two cases, and require refusal without publishing or printing the address.

4. **U4-R2-04 — P2 — The notices package drops a shipped SPDX copyright statement.**
   `tools/generate_third_party_notices.py:139`, `tools/test_third_party_notices.py:27`. **Inspected and reproduced against installed packages.** `@tauri-apps/plugin-dialog` 2.8.4 ships `LICENSE.spdx`, containing `PackageCopyrightText: 2019-2022, The Tauri Programme in the Commons Conservancy`. The generator excludes `.spdx`, reports that this package ships no licence file and has no declared authors, and omits that copyright text. The wider-net test shares the exclusion; the complete notices check and test both passed.
   **Closing test:** Require the package's declared copyright information in the generated output. Removing it must fail an independent inventory check. This finding concerns the promised artifact's completeness, without making a legal-compliance determination.

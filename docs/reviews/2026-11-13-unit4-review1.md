2. **U4-R1-02 — P2 — Encoded and opaque files pass the private-data scan.**

   **Reproduced.** A harmless file named `review.owner@private.invalid.txt` was published. Supplying a literal extra pattern for `review.owner` still produced no hits because only blob contents are scanned. Private names can therefore survive in paths.
   **Closing test:** Match identity and extra patterns against paths as well as contents. Diagnostics must avoid reproducing a private matched filename.

4. **U4-R1-04 — P2 — Email exemptions permit ordinary private addresses.**
   `tools/make_public_snapshot.py:148`
